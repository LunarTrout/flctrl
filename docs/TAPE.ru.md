# Лента: каждое поле, что значит, как читать

[English](TAPE.md) · **Русский**

Лента — единица описания в библиотеке. Одна лента на дорожку на снимок, плюс производные
слои (события, маскировка, провенанс).

Всё ниже считает `flctrl.timbre.analyze(stereo, fs)` и собирает `flctrl.live`.

---

## 1. Сетка

| Параметр | Значение | Примечание |
|---|---|---|
| Клетка (шаг) | 0.1 с | аргумент `hop_s`, можно менять |
| Окно анализа | 4096 сэмплов | ~93 мс на 44.1 кГц |
| Окно | Ханна | |
| Полосы | 28 третьоктав | 25 Гц … 12.5 кГц, `FC` в `incr.py` |
| ERB | 24 полосы | геометрическая сетка 25 Гц … 12 кГц |
| Нижняя граница f0 | 45 Гц | ниже одного окна не хватает |
| Блоки громкости | 400 мс / шаг 100 мс | BS.1770 через `incr.LoudnessMeter` |

Разрешение по времени и по частоте связаны: 4096 сэмплов дают 21 Гц по частоте, но
размазывают всё короче ~93 мс. Поэтому короткие события живут в отдельном слое
(см. [LIVE.ru.md](LIVE.ru.md) и `events.py`).

## 2. Поля клетки

### Громкость и уровень

| Поле | Единица | Смысл |
|---|---|---|
| `rms_db` | дБFS | RMS клетки, среднее L/R |
| `peak` | линейно | абсолютный пик сэмпла в клетке |
| `crest_db` | дБ | пик / RMS; высокий = транзиент, низкий = сжато или тянется |
| `lufs_st` | LUFS | кратковременная громкость блока 400 мс, начинающегося с этой клетки |

### Динамика

| Поле | Единица | Смысл |
|---|---|---|
| `attack_s` | с | время от 10 % до 90 % пика клетки |
| `decay_db` | дБ | спад от пика до RMS хвоста внутри клетки |
| `flux_db` | дБ | изменение уровня к предыдущей клетке |
| `zcr` | 0…1 | частота переходов через ноль — шум против тона, дёшево |
| `hits` | штук | регулярные пики внутри клетки, если они периодичны 6–40 Гц |

### Спектр

| Поле | Единица | Смысл |
|---|---|---|
| `bands` | дБ | 28 третьоктавных мощностей; синус единичной амплитуды даёт 0 дБ |
| `erb` | дБ | 24 ERB-подобные полосы, ближе к слуху, чем третьоктавы |
| `centroid_hz` | Гц | центр тяжести спектра — яркость |
| `spread_hz` | Гц | стандартное отклонение спектра — его ширина |
| `flatness` | 0…1 | 1 = шум, 0 = тон |
| `rolloff_hz` | Гц | частота, ниже которой лежит 85 % энергии |

### Тон и гармония

| Поле | Единица | Смысл |
|---|---|---|
| `f0_hz` | Гц | основной тон (автокорреляция по самым громким 2048 сэмплам; запасной путь — спектр) |
| `note` | имя | ближайший класс высоты по пику хромы (пусто, если f0 = 0) |
| `hnr_db` | дБ | гармоничность: >8 дБ тонально, <0 шум |
| `chroma` | 12 × 0…1 | распределение по классам высоты, нормированное |
| `harm` | 5 × дБ | уровни 2f0…6f0 относительно f0 |
| `inharm` | 0…1 | доля энергии вне гармонического ряда |
| `formants` | до 3 × Гц | пики сглаженной спектральной огибающей (200–4000 Гц) |

### Поведение полос

| Поле | Единица | Смысл |
|---|---|---|
| `low_db`, `mid_db`, `high_db` | дБ | энергия в 20–200, 200–2000, 2000–16000 Гц |
| `decay_bands` | дБ/с | скорость спада внутри клетки по тем же трём полосам |
| `wall` | 0…1 | плотность: доля середины плюс шероховатость; 0 прозрачно, 1 стена |

### Стерео

| Поле | Единица | Смысл |
|---|---|---|
| `corr` | −1…1 | корреляция L/R в клетке |
| `width` | 0…1+ | энергия сайд / энергия мид |
| `pan` | −1…1 | баланс энергии L/R (−1 жёстко влево) |
| `coherence` | 3 × 0…1 | когерентность L/R по группам полос: 1 моно, 0 независимо |

## 3. Поля дорожки

| Поле | Единица | Смысл |
|---|---|---|
| `lufs` | LUFS | интегральная громкость с гейтингом BS.1770 |
| `lra` | LU | диапазон громкости (95-й − 10-й процентиль блоков) |
| `sii` | 0…1 | грубая доля разборчивости (500–4000 Гц против всего) |
| `harmony` | объект | `pitch_classes` (12), близость к `major`/`minor` с корнем, `top` ступени |
| `checks` | объект | `dc`, `clip_samples`, `mono_corr` |
| `transients` | объект | `onsets`, `onsets_s`, `attack_ms` и `ts_db` по полосам |
| `mod_rate_hz`, `mod_depth` | Гц, 0…1 | амплитудная модуляция: биения язычков, тремоло |
| `jitter_pct` | % | нестабильность f0 по клеткам с уверенной высотой |
| `technique` | объект | `rate_hz`, `fast`, `per_cell` — ровный темп щипков/дроби на сетке 5 мс |
| `rms`, `peak`, `silent` | дБFS / линейно / bool | сводка по снимку |

## 4. Слои на весь снимок (меж-дорожные)

| Поле | Смысл |
|---|---|
| `masking` | `pairs`: `{masker, target, band_hz, db}` для пар, разошедшихся на ≥10 дБ в полосе |
| `provenance` | каждые 0.5 с: `{t, bar, active:[каналы/паттерны/клипы]}` из `clip.at` |
| `position` | `{start_seconds, bpm}` — привязка снимка к песне |
| `backup` | точка сохранения: `{ok, file, origin: "save"|"autosave", points}` |
| `cleaned` | сколько пустых файлов убрано из `Recorded` |

## 5. Размер

Измерено на реальном материале (барабаны, 1.52 с, 15 клеток):

| Элемент | Байт |
|---|---|
| одна клетка | ~1029 |
| все клетки | 15 448 |
| события | 1 486 |
| вся лента (JSON) | 22 512 |

Масштаб: 14.5 КБ в секунду на дорожку; 29 дорожек тестового проекта × 10 с ≈ 4.1 МБ. Сырого PCM на тот же
звук — 97.6 МБ.

Практическое правило: ленты держать в памяти, звук — только если его надо слушать.

## 6. Как это читать

Читать ленту как доказательства, а не как ярлыки:

- **Уровень и динамика** — `rms_db` вместе с `crest_db`: высокий крест означает удары,
  низкий при высоком RMS — тянущийся или пересжатый материал.
- **Яркость** — `centroid_hz` и `high_db − low_db`. Сдвиг на 3 дБ в верхней полосе
  заметно двигает центроид; это и есть число, которое стоит называть.
- **Тон против шума** — `hnr_db` и `flatness` разделяют дисторшн-гитару и тарелки без
  всяких названий инструментов.
- **Высотное содержание** — `f0_hz` + `chroma` + `harm`: у риффа устойчивый f0 и
  гармонический ряд; у негармонического удара (`inharm` около 1) — нет.
- **Стерео** — `corr` и `width` вместе: 0.95/0.15 — моно-источник в центре; 0.2/0.6 — два
  независимых источника, разведённых по краям.
- **Изменение во времени** — всплески `flux_db` отмечают границы секций и атаки; `lufs_st`
  показывает контур громкости.
- **Шины против источников** — шина коррелирует со своим источником (у нас 0.61 для
  DRUM BUS ↔ DRUMS SD3) и обычно на несколько дБ громче в тех же полосах. Это не дубль.

---

## 7. Чего в ленте намеренно нет

- Названий инструментов и меток техники. Эвристики убраны осознанно: числа плюс контекст
  честнее, чем догадка, поданная как факт.
- Дельт к референсу. Это шаг сравнения, а не одного снимка.
- Сэмпловых волн. Если нужен звук — он запрашивается явно (`tracks.dump`).
