# Правила, добытые на живых проектах

[English](RULES.en.md) · **Русский**

Это не пожелания, а вещи, которые стоили падений FL и потерянного времени. Соблюдать в
каждом новом проекте.

---

## 1. Не писать параметры очередью

Каждая запись — сообщение в UI-поток FL. Пачка из десятков подряд (особенно на играющем
транспорте) роняет движок: крэш в `USER32` → `FLEngine+0x246F9E`, чтение нуля по `0x90`.

Писать через `fl_set_params` / `fl.act.param_batch`: транспорт стоп, пауза ≥0.1 с между
записями, автосохранение каждые четыре.

## 2. У полос Pro-Q четыре разных «включено»

Параметров на полосу 23: `+0` Band Used (моментальная кнопка, чтение всегда врёт нулём),
`+1` Enabled (настоящий выключатель), `+2` Frequency, `+3` Gain, `+4` Q, `+5` Shape,
`+6` Slope. Наличие полосы проверять только по `+1`.

## 3. Split mixer tracks работает только с WAV

С MP3/OGG/FLAC галочка игнорируется. CLI-рендер (`/R`) **не** делит на дорожки — даёт
один мастер; сплит доступен только через диалог экспорта. Путь `/R` FL понимает как папку.

## 4. Пустое имя в диалоге экспорта = рендер в никуда

FL проходит все такты и пишет ноль файлов. Имя подставлять не нужно — своё подставит сама.

## 5. Синтетические нажатия в диалогах экспорта роняют FL

Кнопки DirectUI не берут `BM_CLICK`, `SetFocus` не срабатывает, а Keyboard-события
приводят к крэшу. Диалог экспорта оставлять человеку, автоматизировать только CLI.

## 6. Шина без источников молчит

Мьютить «всё кроме шины» бессмысленно: источники шины тоже глушатся. Для замера шины
оставлять её источники.

## 7. Сравнивать только одинаковые участки

Замер стема на 180–210 с и живой захват на 35-м такте — разные места трека; расхождение
профиля на 2–4 пункта означает именно это, а не ошибку обработки.

## 8. Слух живёт в отдельном окружении

`phonometry` есть только в 3.13; основной процесс (3.12) зовёт `hear_cli.py` подпроцессом.
Интерпретатор выбирается проверкой `import phonometry`, а не по имени папки.

## 9. Эмбеддинги и стиль требуют torch

`describe` / `style` идут через интерпретатор с torch — искать перебором, а не вбитым путём.

## 10. У Fortin Nameless параметры пишутся, но не читаются

`getParamValue` возвращает 0.5 для всех ручек, поэтому «скопировать значение как есть»
нельзя — получится ноль. Считать норму от диапазона:

- проценты (Middle, Treble, Presence, MVC, Bass, Gain): `норма = процент/100`;
- EQ (250/500/1k/2k/4k, ±12 дБ): `норма = 0.5 + дБ/24`;
- дистанция кабинета: 1:1 (`0.15` = 0.15 м);
- уровень кабинета нелинеен: 0.0 → −40 дБ, 0.05 → −14.9, 0.10 → −11.1, 0.15 → −8.6,
  0.20 → −6.7, 0.35 → −2.8, 0.45 → −0.8;
- микрофон кабинета: 0.00 Dynamic 57, 0.10 Dynamic 421, 0.25 Dynamic 906,
  0.45 Condenser 184, 0.60 Ribbon 121, 0.80 Ribbon 160, 0.95 Custom IR.

Проверять каждую запись чтением строки — иначе легко «скопировать» усилок в ноль.

## 11. Захват дорожек: только song mode

В pattern mode FL играет выбранный паттерн, а не песню — снимок выходит пустым. Захват
всегда переключает режим в song и возвращает прежний после.

## 12. Модальное окно «Recording» останавливает автоматизацию

`transport.record()` через мост поднимает диалог, и FL перестаёт отвечать на команды.
Лечится `PopupRec = 1` в `HKCU\Software\Image-Line\FL Studio 25\DSTITF`
(`live.suppress_popup`), иначе снимок зависает.

## 13. Хук нельзя выгружать, пока поток записи внутри него

Снятие Frida-скрипта в этот момент роняет FL. Поэтому хук живёт в отдельном демоне
(`hook_daemon.py`) с одной привязкой на сессию; выгрузка — только по `quit`, после
остановки записи и паузы.

## 14. Не снимать на рабочем проекте без спроса

Запись в song mode может вставить аудиоклип в плейлист («auto-create audio clip»).
Снимать на рабочем проекте — только с разрешения; безопаснее копия проекта.

## 15. Точка сохранения перед каждым рискованным шагом

Ctrl+S и копия `.flp` в `~/Backups/flctrl/` до захвата или массовой правки. История undo
живёт в памяти и умирает вместе с процессом; файловая точка переживает падение.

## 16. Запись оставляет клипы в плейлисте — гасить на время снимка

FL при записи armed-дорожки пишет WAV и вставляет его клипом в плейлист (микшер →
Disk Recording → **Auto-create audio clip**). Клипы накладываются друг на друга, и в этом
месте проект звучит в разы громче.

Ловушка в том, что вставка происходит **при сохранении проекта**, а не в момент записи:
если просто погасить `AutoCreateClip` на время записи и вернуть обратно, клипы всё равно
появятся при следующем Ctrl+S. Поэтому `live.capture()` делает три вещи: гасит
`AutoCreateClip` (FL читает его в момент записи), после снимка откатывает шаг записи через
`general.undoUpDown(-1)` и возвращает флаг как был. Своя запись пользователя при этом
работает по-прежнему — клипы создаются.
