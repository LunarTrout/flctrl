# Исследования: что нарыли и что из этого следует

Здесь лежат все три отчёта и данные, собранные по теме «как объективно свести
трек к идеальному балансу и как это перенести на другие проекты».
Всё — первоисточники: AES, ISMIR, arXiv, журналы, GitHub. Ничего «по памяти».

## Главные выводы, ради которых всё собиралось

1. **Готового инструмента «баланс по ролям для произвольного набора
   инструментов» не существует.** Ближе всего — ELL (equal local loudness),
   unmasking-панорама и корпусные цели. Это и собираем.
2. **Слышимость ≠ громкость.** Частичная громкость `N_partial = N(микс) −
   N(микс без источника)`, слышимость `A = N_partial / N_solo`. Текущие доли
   полос завышают вклад тихих источников в 4–5 раз.
3. **Баланс в две ступени** (внутри группы → между группами) значимо лучше
   одноступенчатого; неверная группировка вредит сильнее ошибок громкости.
4. **Цели — распределение корпуса, а не абсолют.** Типоспецифичная
   нормализация (FxNorm) доказала переносимость между треками.
5. **Маскировка структурна по жанру**: в роке гитары наименее маскируемы,
   затем вокал, бас, барабаны; связь гитары↔вокал тесная, барабаны↔бас слабее.
6. **Люди сводят последовательно**, стем за стемом (sequential stem blending),
   и разные инженеры сходятся к согласованному балансу (mix-space).
7. **Эффекты меряются тремя разными пробниками** (линейные / нелинейные /
   время-зависимые); SI-SDR, null-тест и PESQ/STOI для музыки не годятся.
8. **Один трек как референс — переобучение.** Рабочая схема: корпус и
   распределение; один трек только для слепого A/B.

## Чего в литературе нет (и мы это признаём)

- Единой объективной метрики качества микса — все существующие прокси.
- Жанровых нормативов баланса и корпуса «миксы + стемы + роли + жанр».
- Таксономии ролей инструментов, пригодной для любого проекта.
- Открытого Python-пакета для частичной громкости (эталон AMT — GPL-3,
  `phonometry` даёт только специфическую громкость N′(z)).
- Предсказания нелинейных эффектов без реального замера.
