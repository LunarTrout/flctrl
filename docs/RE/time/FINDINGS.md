# FINDINGS: time

Лейн `time`: точное время (позиция в сэмплах), темп, размер, карта смен темпа,
живой плейлист и паттерны (ноты с локальным временем).

## 0. Обстановка (проверено 2026-11-03)

- **В FL открыт `vers1.flp`, а не `demo2.flp`** (заголовок окна `vers1.flp - FL
  Studio 2025`, pid 159440). Брифинг говорит «открыт demo2» — это не так.
  Живые замеры, меняющие состояние (темп, транспорт), на `vers1` не делаю:
  проект рабочий, правило №1. Только пассивное чтение.
- Мост TCP 9787 отвечает `FLNotRunning` («controller is not responding») — сверка
  с `transport.getSongPos()` / `mixer.getCurrentTempo()` сейчас невозможна.
  Причина не в локе: лок держит `ctrl`.
- FLEngine_x64.dll: база `0x74200000`, размер `0x3A40000` (61 087 744 Б).
  RW-памяти в процессе ~7.9–8.3 ГБ (3371 диапазон) — полный скан ≈ 26 с,
  но Frida-хелпер периодически падает на инъекции (`_o_localeconv`), поэтому
  частые attach/detach не делать: одна сессия на пачку замеров.

Проверено на `demo2.flp` и `vers1.flp` (только чтение файла, FL не трогал).

| размер | `0x11`/`0x12` (17/18) | u8 числитель / знаменатель | 4/4 | 4/4 |

Раскладка записи плейлиста (FL 25, 80 Б) — подтверждена на 647 записях demo2:

**Единицы start_offset/end_offset — миллисекунды, проверено по файлу:**
клип `Main Vocal` (demo2) имеет `0..18497.6`; OGG
`PL_TLO_05_With You_104_Lead Vocals_01_A_D#m_Dry.ogg` из
`C:\Programs\Fl Studio 2025\Data\Patches\Misc\Used by demo projects\...`
имеет длительность 18.462 с = 18462 мс (расхождение 0.2 %). Не секунды
(18497.6 с невозможны) и не сэмплы. Для pattern-клипов там NaN или 0/length.

Запись ноты (24 Б): `u32 pos, u16 flags, u16 rack_channel, u32 length,
u16 key, u16 group, u8 fine_pitch, u8 _, u8 release, u8 midi_channel,
u8 pan, u8 velocity, u8 mod_x, u8 mod_y`. Проверено: первая нота demo2 —
pos=48, key=72, len=48, vel=100, channel=8, fine_pitch=120 (0 центов).

## 2. Живая память — что проверено и что нет

- Строковый поиск по всей RW-памяти работает (26 с на проход), но короткие
  строки дают ложные попадания в коде: `"Tempo"` (8 хитов) и
  `"Superior Drummer 3"` (8 хитов) находятся в текстовых буферах путей
  (`...\Generators\VST3\Superior Drummer 3.fst`), не в объектах каналов.
  `"Main Vocal"`, `"demo2"`, `"fltest"` — 0 попаданий (проект другой).
- `double 126.0` и `u32 126000` в RW-данных FLEngine — **0 попаданий**;
  `float 126.0` — 2 попадания, оба невыровненные и внутри кода (ложные).
  Значит темп не лежит простым числом в статических данных движка —
  он в объекте кучи.
- Дальше иду по RTTI Delphi: имена классов (`TSong`, `TPlayList`, `TPattern`,
  `TChannel`) → VMT → экземпляры (первый qword объекта = VMT).
