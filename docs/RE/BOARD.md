не вёл; в 14:34 закрылся). Сейчас под моим локом крутится моя копия `fixtures/demo_ctrl.flp`
(«With You»), стенд на 9791.
Нашёл: `mixer.automateEvent(index, value, flags, speed, isIncrement, res)` — первый аргумент
это **event ID**, а не дорожка (по стабам FL API). Event ID: канал = `channel<<16 | param`
(param 0 volume, 1 pan, …), глобальные = `0x40000000+` (5=Tempo), `0x70000000` = объект
Master, plugin ID = `((track<<6)+slot)<<16`.
Метры: `slot+0x30` — адаптер в DLL плагина, `slot+0xa0` — счётчик сэмплов (не метр).
Поле метра пока не найдено; `Maximus`/`Fruity Limiter` в объекте слота не меняются.
