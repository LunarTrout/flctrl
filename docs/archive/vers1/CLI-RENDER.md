# ПРОРЫВ: рендер из командной строки (без моста и GUI)

## Проверено и работает

```
cd "C:\Programs\Fl Studio 2025"
FL64.exe /Ewav /R"<путь>\out.wav" "<путь>\project.flp"
```

- FL открывает проект, рендерит, закрывается — **без единого клика**.
- Проверено на `vers1.flp`: результат `C:\Users\epicc\Desktop\PROJECTS\test\vers1.wav`,
  **352.0 с, стерео, 44,1 кГц, 62 МБ**, читается soundfile.
- Второй экземпляр FL при уже запущенном — не стартует, поэтому перед запуском FL надо закрыть.
- Имя и путь из `/R` FL игнорирует: пишет в папку экспорта проекта под именем проекта.

## Значение

Рендер больше не требует: Ctrl+Shift+R, окна `TWAVRenderForm`, мышu, ожидания GUI.
Это снимает самую дорогую часть цикла сведения — получение звука для замера.

## Что уже расшифровано в `.flp`

| Событие | Содержимое | Размер записи |
|---|---|---|
| `0xE0` (224) | **ноты** — 4684 шт. | 24 байта |
| `0xE5` | каналы рэка — 142 | 20 байт |
| `0xE4` | параметры каналов — 284 | 16 байт |
| `0xEC` | служебное по дорожкам — 32 | 12 байт (не громкость: всюду 76) |
| `0xCC` (204) | **имена дорожек микшера** — 32 | UTF-16LE |
| `0xCB` (203) | **имена каналов** — 144 | UTF-16LE |
| `0xD5` | **плейлист** — записи по 32 байта: position, pattern_base(20480), item_index, length, track, group | 32 байта |

## Что НЕ расшифровано (нужно для правок без моста)

- громкость и панорама микшерной дорожки (не в `0xEC`);
- mute/solo дорожек и каналов;
- маршруты дорожек;
- автоматизация.

## Следующий шаг для офлайн-сведения

1. Найти поля volume/pan/mute: сравнить два сохранённых `.flp` с заведомо разными
   значениями (например, сохранить проект с замьюченной дорожкой и без) — разница
   укажет точное смещение.
2. После этого: правка копии `.flp` → CLI-рендер → замер → следующая правка.
   Полный цикл сведения **без MIDI-моста**.
