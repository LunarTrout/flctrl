# План сведения vers1 — целевые цифры и порядок работ

## 1. Цель (из анализа трёх референсов)

| Параметр | Цель | Сейчас (до правок) |
|---|---|---|
| LUFS-I | −9…−10 | мастер постоянно в лимитере (−0.3…−0.5 dBFS) |
| Пик-фактор | ≥ 13.5 дБ | ~8–9 (убит лимитером) |
| Динамический размах | ≥ 8 дБ | — |
| Низ < 120 Гц | 11–13 % sub + 25–30 % bass | бас молчит, низ не определён |
| 315–500 Гц (маскирование) | −5…−7 дБ от пика | муть не убрана: у барабанов и баса нет EQ |
| Presence 4–8 кГц | 4–6 % | 2.4 % у GRIMA, у нас не измерено |
| Наклон 500 Гц → 8 кГц | −1.5…−2.0 дБ/окт | — |
| Корреляция L/R | 0.45–0.55 | гитары строго ±1.0 |

## 2. Архитектура микшера (план)

Сейчас всё летит прямо в мастер. Предлагается 4 шины на свободные инсерты:

| Шина | Куда | Источники |
|---|---|---|
| GTR BUS | Insert 31 | 22, 23, 9, 10 (усилки) + 26, 27, 28, 29 (слои) |
| DRUM BUS | Insert 24 | 1 (SD3) + 15, 16 (перкуссия/лупы, если это они) |
| VOX BUS | Insert 20 | 25 (настя 001–006) + вокал, который сейчас на 23 |
| AUX BUS | Insert 17 | 5, 6 (атмосферы), 30 (mp3-референс — лучше вообще мимо) |

Даёт: одну ручку на группу, место для общей обработки, мастер перестаёт собирать 12 источников.

## 3. Гитары (4 разных усилка — каждый отдельно)

Проблемы, найденные у трека 22 (остальные проверить, они могут отличаться):
- `EQ High Pass` = 20 Гц (фактически выключен) → нужно **100–120 Гц**;
- `EQ Low Pass` = 20 кГц → **8–10 кГц** (убирает физз);
- `EQ 8 kHz` = **+4.6 дБ** → в 0 (это и есть «шипение»);
- `Amp Bass` 75 % → 45–55 % (муть);
- `Amp Presence` 15 % → 25–30 % (артикуляция);
- `Amp Treble` 34 % → 40–45 %;
- `Gate Threshold` −77.7 дБ (гейт всегда открыт) → −60…−65 дБ (собрать мысль без потери сустейна).

**Порядок:** сначала восстановить исходные значения на 22, потом по одному параметру на каждом из четырёх усилков, с замером после каждого шага. Никаких массовых записей.

## 4. Барабаны (Insert 1) и бас (Insert 2)

FL API не загружает плагины, поэтому нужен `Fruity Parametric EQ 2` в слот 0:
- барабаны: HPF 30 Гц, вычет 250–400 Гц (−2…−3 дБ), контроль 2.5–4 кГц;
- бас: HPF 30–40 Гц, вычет 250–400 Гц, подъём 700–900 Гц для читаемости под четырьмя гитарами.

## 5. Восстановление трека 22 (исходные значения усилителя)

| Параметр | Вернуть |
|---|---|
| EQ High Pass | 20 Hz |
| EQ Low Pass | 20.0 kHz |
| EQ 8 kHz | +4.6 dB |
| Amp Bass | 75 % |
| Amp Presence | 15 % |

(Текущие: HPF 114 Hz, LPF 6.98 kHz, EQ8k −0.0 dB, Bass 50 %, Presence 25 %, Treble 25 %, Gate −63 dB.)

## 6. Бюджет нагрузки

FL берёт ~364 % одного ядра при 16 доступных. Smart disable + байпас Ozone на мастере во время сведения; финальный мастер — отдельным этапом.
