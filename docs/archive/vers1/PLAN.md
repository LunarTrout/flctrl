# План правок vers1 по измерениям (корректное сравнение)

## Методика

Стемы Demucs по всему треку (352 с). **Сумма стемов нормируется к −23 LUFS**, затем каждый стем меряется относительно суммы. Нормировка каждого стема отдельно — неверна: она уничтожает баланс.

|---|---|---|---|---|
| барабаны | −12.6 | −8.4 | −4.7 | **тише на 4–8 дБ** |
| бас | −2.9 | −4.9 | −7.5 | **громче на 2–5 дБ** |
| вокал | −8.1 | −11.9 | −9.9 | **громче на 2–4 дБ** |
| гитары | −7.7 | −5.0 | −7.1 | в норме |

Сходится с жалобами: барабанов не слышно, вокал громко, бас глушит бочку.

## Атрибуция (PANNs + кластеризация тембра)

- вокал: мужской скрим 59 % трека (Speech 0.38 / Groan / Yell); женский 13 % — 1:54–2:28 (Female singing 0.38), второй вход 4:22–4:34;
- барабаны: два характера (Drum 0.57 и Drum kit 0.68); 5:34–5:48 — неразборчивый шум;
- бас: три характера; в 1:54–3:03 уходит в гул (Singing bowl 0.17);
- гитары: три слоя — яркий 0.87 (46 %), средний 0.76 (20 %), глухой 0.31 (29 %).

## Блокер

Подтверждение правок замером требует работающего FL. Проект падает при загрузке на создании **FabFilter Pro-L 2** (4 экземпляра, падение на последнем). flapi не отвечает.
