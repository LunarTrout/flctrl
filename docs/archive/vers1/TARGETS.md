## Цель для vers1 (тело GRIMA + читаемость Wintersun)

**Инструментал:** низ 50–54 %, mud ≤3 %, mid 12–15 %, presence 4.0–4.8 %,
air 0.8–1.2 %, crest 12.5–13.5 дБ, корреляция 0.48–0.52, наклон −4.5…−5.0 дБ/окт.

**Вокал:** mid 58–66 %, mud ≤8 %, presence 3.5–4.5 %, air 2.5–3.5 %, crest 16–19 дБ.

## Ключевой вывод

Wintersun держит низ на 59 % при мути **1.4 %** — «современный плотный низ без грязи».
GRIMA: низ 42–47 % при мути 7 % — телесно, но размыто. Значит правильное движение:
**низ поднимать, муть вычищать**, а не просто «делать ярче».

## Что осталось измерить

Рендер шин из FL (`DRUM BUS`, `BASS`, `VOX BUS`, `GTR L/R BUS`) → прогнать `refcompare.py`
против профилей выше и получить построчный список дБ для правки по каждому инструменту.

## Прогресс по рендерам (закрытый цикл)

Цикл: правка через flapi → экспорт (`Ctrl+Shift+R` + буфер обмена + Enter, `tools-local/fl_export.py`)
→ измерение `refcompare.py` → новая правка.

**Вывод:** тональный баланс сдвинут в нужную сторону (низ и середина попали в цель),
но уровень был перекручен — клиппинг и пережим лимитером. Правки V3: мастер-фейдер
0.62, вход лимитера +11.1 дБ, presence мастера +3.5 дБ на 5059 Гц.

## Следующий шаг по инструментам

В окне рендера FL включить «**Split mixer tracks**» — он отдаёт по файлу на каждый инсерт
(рендер с микшера, без нарезки плейлиста). Затем сравнить каждый стем с demucs-стемом
референса и править по разнице.
