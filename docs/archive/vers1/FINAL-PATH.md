# ИТОГ: путь к идентичному звуку

## Главный вывод

**Идентичен только рендер самого FL.** Никакая конвертация в другую DAW не даст
того же звука, потому что у FL встроенные движки (Fruity Limiter, Parametric EQ)
не существуют как VST, а состояние Kontakt/SD3 в принципе не переносится.

## Что проверено и работает

1. **Рендер FL из командной строки** — без GUI, без MIDI-моста:
   ```
   cd "C:\Programs\Fl Studio 2025"
   FL64.exe /Ewav /R"out.wav" "C:\Users\epicc\Desktop\PROJECTS\vers1\vers1.flp"
   ```
   Результат: `PROJECTS\test\vers1.wav` — **352.0 с, стерео, 44.1 кГц, 62 МБ**. Это идентичный звук FL.

2. **REAPER установлен**, видит все плагины (122 записи): Kontakt 7, Superior Drummer 3,
   EZbass, Fortin Nameless Suite X, Pro-L 2, Pro-Q 4, ValhallaVintageVerb.
   Путь VST прописан в `reaper.ini` → `[reaper] vstpath=`.

3. **Конвертация Doseedo FLP→RPP выполнена** (`PROJECTS\vers1_reaper\`): 59 дорожек,
   778 клипов, 4684 ноты, темп 155.5 с огибающей.

## Почему конвертация не идентична (проверено)

| Проблема | Детали |
|---|---|
| автоматизация | перенеслась только огибающая темпа |
| Kontakt | 3 дорожки есть, инструментов на них нет → баян и цимбалы молчат |
| вокал | дорожки и клипы на месте, в миксе не слышно |
| растяжение | у 128 из 778 клипов `PLAYRATE` 0.55–0.87 (исправлено на 1.0 — это предположение, не перенос) |
| плагины FL | Fruity Limiter / Parametric EQ отсутствуют как VST |

## Что делать, чтобы получить стемы

**Вариант А (2 клика, сразу):** FL → Render (Ctrl+R) → включить *Split mixer tracks* → Export.
FL отрендерит каждый инсерт отдельным WAV — это идентичные стемы.

**Вариант Б (без человека, не сделано):** найти в `.flp` байт, включающий *Split mixer tracks*.
Метод: сохранить проект дважды (с галочкой и без) и сравнить файлы — разница укажет байт.
Требует одного сохранения из GUI.

## Что НЕ расшифровано в `.flp`

- плейлист (клипы) — `0xDA` проверен и отвергнут: 710 событий по 68 байт,
  1420 записей, все поля одинаковы (100, 20000) → это не плейлист;
- громкость/панорама/mute микшерных дорожек (в `0xEC` их нет — там всюду 76).
- Парсер `flp_events.py` исправен: самопроверка сходится байт в байт (8651 событие).
