# Сведение по одному референсу, без стемов

Референс приходит одним стереофайлом. Стемов нет и не будет. Здесь описано, как из этого
ограничения делается рабочий метод.

---

## 1. Почему не разделять референс

Разделение готового мастера теряет именно то, что нужно для баланса: гитары протекают в
вокал, барабаны размазываются во всё подряд. SDR у музыкальных стемов — единицы дБ:
достаточно, чтобы *послушать*, недостаточно, чтобы ставить по нему фейдер. И ошибка
разделения не случайна: она коррелирует с той самой маскировкой, которую мы измеряем.

Поэтому референс используется как **вектор целей**, а не как набор дорожек.

## 2. Постановка

Наш микс по полосе `b` и отрезку времени `t` в первом приближении линеен по гейнам:

```
M[b, t] = Σ_i  g_i · a_i[b, t] · X_i[b, t]
```

где `X_i` — измеренная энергия дорожки в полосе, `a_i` — её EQ-поправка в этой полосе,
`g_i` — гейн. Референс даёт цель `R[b, t]`.

Задача: найти `g` (и небольшой EQ на дорожку), минимизируя

```
Σ_{b,t}  w[b,t] · ( M[b,t] − R[b,t] )²   +  λ · ‖g − 1‖²
```

при ограничениях:

| Ограничение | Зачем |
|---|---|
| `|g_i| ≤ 6 дБ` | не ломать аранжировку ради числа |
| `|EQ_i[b]| ≤ 4 дБ` на широкую полосу | только широкие ходы; хирургический EQ — не инструмент баланса |
| иерархия ролей сохраняется | барабаны не должны стать тише гитар |
| цель по громкости ±0.5 LU | сдвиг уровня не «решается» одними фейдерами |

Регуляризация принципиальна: без неё решатель с радостью предложит экстремальные гейны,
которые совпадут с референсом и испортят микс. Ядро этого уже есть в `invmix.py`;
не хватает построителя целей (ниже).

## 3. Построение целей из стереофайла

`reference.frame(path)` — следующий модуль — даёт кадр с теми же осями, что наша лента:

| Ось | Разрешение | Почему так |
|---|---|---|
| время | секции, не клетки | у референса нет дорожек; посэмпловое совпадение — шум |
| полоса | третьоктава или октава | достаточно мелко для баланса, достаточно крупно для устойчивости |
| метрика | уровень, громкость, ширина, центроид, плотность транзиентов, LRA | то, что референс реально может задать |

Секции режутся по форме самого референса: изменения контура LUFS и плотности онсетов.
Наша песня сегментируется так же, а затем две разбивки выравниваются **по порядку и
относительной форме**, никогда по абсолютному времени — темп и длины разные.

## 4. Что сматчится, а что нет

| Сматчится | Не сматчится |
|---|---|
| баланс полос по секциям | точный тембр инструмента |
| контур громкости и LRA | инструменты, которых у нас нет |
| ширина и корреляция по полосам | исполнение и аранжировка |
| плотность транзиентов (степень компрессии) | комната и характер микрофонов |
| траектория центроида | артефакты нелинейной обработки |

Нелинейная обработка (компрессия, сатурация) сматчивается косвенно — через LRA, крест и
плотность транзиентов, а не через уровни полос, которые она меняет неравномерно.

## 5. Петля

```
reference.frame(path)            → цели
tracks.live(seconds, start)      → наша лента по дорожкам
invmix.solve(tape, targets)      → {gain_i, eq_i, pan_i}
применение                       → фейдеры / EQ / панорама вживую
tracks.live(...)                 → измеряем снова
compare(tape_before, tape_after) → дельта к цели
```

Останавливаемся, когда дельты по полосам в пределах ±1…2 дБ, а по громкости ±0.5 LU, либо
когда дальнейшие ходы нарушают ограничения. Каждый шаг — число, значит каждый шаг
воспроизводим и откатываем.

## 6. Практические замечания

- Снимать один и тот же участок дважды: до хода и после. Сравнение разных частей песни —
  классический способ измерить аранжировку вместо микса.
- Брать у референса *форму*, а не абсолютный уровень: мастер на −9 LUFS и наш микс на
  −14 LUFS не «неправильные», они на разных стадиях.
- Следить за `masking` во время решения: гейн, который улучшает баланс полос, но
  увеличивает маскировку в 2–5 кГц, — это регресс.
- Держать точки сохранения включёнными: решатель предлагает, инженер принимает, FL всегда
  можно откатить.

## 7. Текущее состояние

Сделано: `tracks.live`, `timbre`, `events`, `frames.compare`, `invmix` (ядро решателя),
`clip.at` (провенанс).

Не хватает: `reference.frame()` (построитель целей из одного файла) и выравнивания секций.
Пока их нет, сверка с референсом делается руками: измерить референс через `timbre.analyze`,
измерить свой микс, сравнить кадры и решить.
