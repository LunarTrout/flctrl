# flstudio-lib

Библиотека доступа к FL Studio 25: видеть проект, слышать результат, крутить
что угодно и создавать объекты — без скриншотов и без ручных кликов.

Заточена под FL Studio 2025 (25.2.5) на Windows, но большинство слоёв работает
с файлом `.flp` и с любым мостом управления.

## Что внутри

| Раздел | Назначение |
|---|---|
| `fl_lib.py` | единая точка входа: `state`, `hear`, `act`, `monitor`, `sim`, `predict`, `create`, `safe` |
| `listen_layer.py` | слой слуха: ISO 532-1 (соны, фоны, N′(z) по 240 полосам Барка), DIN 45692, ECMA-418-2, STOI, маскировка, коридор |
| `perceptual.py` | движок phonometry: третьоктавные полосы, калибровка, Zwicker |
| `sandbox.py` | песочница: набор ручек (gain / hpf / lpf / eq / comp / sat / pan / vst3) в любом порядке |
| `predict.py` | предсказание результата правки без её применения (аддитивная модель мощности) |
| `liveview.py` | живая оценка микса по профилям дорожек и пикам |
| `bandprofile.py` | многoосевой профиль по 240 полосам: уровень, ширина, модуляция |
| `bandcompare.py` | сравнение с референсами по 240 полосам |
| `judge.py` | приёмка правки: значимость, цель, побочный ущерб, журнал |
| `describe.py` | узнавание: эмбеддинги PANNs, косинус, поиск похожего |
| `mixstyle.py` | стиль сведения: эмбеддинг MIXSTYLE FXencoder (2048) |
| `sections_profile.py` | профиль всего трека по секциям |
| `profile_cache.py` | один расчёт на файл, дальше чтение мгновенное |
| `fl_automation.py` | чтение автоматизации из `.flp` (событие `0xEA`) |
| `fl_add_plugin.py` | вставка плагина в проект через `.fst` |
| `fl_clone_plugin.py` | копирование записи плагина в другой слот |
| `fl_reload.py` | автоперезапуск проекта |
| `safe_fl.py` | безопасный запуск FL только с тестовым проектом |
| `track_capture.py` | захват выхода звуковой карты, соло дорожки |
| `brief.py`, `q.py` | готовые отчёты и запросы из командной строки |

## Установка

Два окружения, потому что `phonometry` требует Python ≥3.13, а `pyflp` и `frida`
живут в 3.12:

```bash
uv venv --python 3.13 .venv313
uv pip install --python .venv313/Scripts/python.exe phonometry soundfile numpy scipy pyloudnorm pystoi fastparquet

uv venv --python 3.12 .venv312
uv pip install --python .venv312/Scripts/python.exe sounddevice "git+https://github.com/stemhub-org/PyFLP_v2.git@dev"
```

Для VST3-песочницы: `uv pip install --python .venv313/Scripts/python.exe pedalboard`.

## Быстрый старт

```python
import fl_lib as fl

# видеть
fl.state.tracks()            # живой микшер
fl.state.plugins()           # слоты и имена
fl.act.params(9, 0)          # все параметры плагина

# слышать
fl.hear.measure("mix.wav", 60, 90)          # N, резкость, LUFS, полосы
fl.hear.measure("mix.wav", stem="vocal.wav")  # + STOI
fl.hear.masking(stems, mix_path="mix.wav")    # кто кого забивает

# предсказать
mix = fl.predict.profile("mix.wav")
trk = fl.predict.profile("gtr.wav")
r = fl.predict.change(mix, trk, -2.0, [(300, -3)])      # громкость и EQ, без применения
for line in fl.predict.lines(r["before"], r["after"]):
    print(line)

# проверить гипотезу с настоящим плагином
x, fs = fl.sim.load("gtr.wav", 60, 80)
y = fl.sim.run(x, fs, [fl.sim.vst(PRO_Q4, bands=[[300, -4, 0.9]])])
fl.sim.delta(*fl.sim.compare(x, y, fs))

# применить вживую
fl.act.param(9, 0, 12, 0.62)
fl.monitor.only(9); fl.monitor.listen(9, 10)

# создать вживую, без перезапуска (Frida)
fl.create.live_start("test.flp")                       # поднять стенд
fl.create.live_slots(1)                                # карта слотов канала 1
fl.create.live_insert(1, 5, "Fruity Limiter")           # вставить в 1:5
fl.create.live_delete(1, 5)                            # освободить
fl.create.live_replace(1, 5, "Fruity Reeverb 2")        # заменить
```

## Ключевые ограничения (проверены, не догадки)

* **Отладчики FL невозможны** — протектор Image-Line убивает процесс за 0.3 с.
  Работает только Frida.
* **Скрипты FL живут в субинтерпретаторе** — `import ctypes` там падает, поэтому
  память и вызовы функций доступны только из внешнего процесса.
* **Вставка плагина через API FL невозможна** — но работает **вживую через Frida**:
  `fl.create.live_insert` вызывает родную функцию движка (1.3 с), удаление —
  `fl.create.live_delete` (1.5 с). Запасной путь — запись в `.flp` плюс перечитывание.
* **Калибровка громкости — только по всему треку**, никогда по отрезку: иначе
  тишина «подтягивается» до нормальной громкости.
* **Стемы нельзя суммировать**: Σ N′ ≈ 1.55× микса.
* **Гитарный стем сепаратора** (SDR ~3 дБ) для выводов о балансе непригоден.
* **MOS-метрики для речи** к музыке не применять.
